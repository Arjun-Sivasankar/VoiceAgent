# TTS benchmark work

This is the source-and-results portion of the TTS work used by `VoiceAgent`.

Tracked here:

- Kokoro and Supertonic-3 benchmark scripts
- Voice-cloning tools and Ultron configuration files
- Benchmark notes and CSV/JSON results
- The selected Kokoro Ultron voicepacks and Supertonic Ultron style

Not tracked here:

- Downloaded model weights and Hugging Face caches
- Python virtual environments
- Generated audio and raw voice-reference recordings
- Tool checkpoints, logs, and local cache data

The active runtime voicepack is `models/kokoro/voices/ultron.pt`.
